# dxdy 📐

**Overview**: dxdy is a real-time practice platform that simulates the format of UTA's Dallas Calculus Bowl, a team-based calculus competition where students race to solve questions and buzz in answers. I built this project after seeing that out team had access to past questions but not efficient way to practice the actual competition format without the physical clickers used at the event. dxdy, however, recreates the competition experience in the browser with multiplayer functionality, allowing teams to practice together and estimate their competitive performance.

**Features**:
 - **Competition Lobbies** - Teachers can host practice sessions and have student teams join a shared lobby
 - **Real-Time Questions** - Questions are synchronized across all teams as the host progresses through the competition
 - **Buzz-In System** - Teams submit answers in real time using the same scoring mechanics as the actual competittion
 - **Past Question Sets** - Past Calculus Bowl questions were organized from Google Slides into a JSON format to create reusable practice sets

**Tech Stack**: HTML, jQuery, Tailwind CSS, Express.js, Socket.IO, Render
