# CarryTheOne 1️⃣

**Overview**: Carry the One is a free collection of tricks and strategies for UIL (University Interscholastic League, Texas competitive organization) Number Sense, created to make more current Number Sense problem solving techniques more accessible to Texas students after seeing that many existing resources were either outdated or provided only by expensive tutoring. The site provides freely accessible explanations of techniques that students can use to improve their individual performance, and I have plans to expand the collection and add practice problem generators for individual tricks soon.

**Features**:
 - **Trick Guides** - Step-by-step explanations of Number Sense tricks and techniques
 - **Markdown Parsing** - Trick explanations are written and maintained using Markdown for easy editing by me and others
 - **Open Access** - All resources are freely available without requiring a subscription or tutor

**Tech Stack**: HTML, jQuery, Tailwind CSS, GitHub Pages
